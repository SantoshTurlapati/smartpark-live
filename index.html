FAQ

Questions, answered.

Can I book a location before it is approved?

No. Pending or rejected locations are visible in this demo, but only approved locations can be booked.

Is this connected to real parking sensors or payments?

No. This is a frontend demo using browser storage. It does not process payments or connect to live sensors.

Will my demo data appear on another device?

No. Demo data is stored in this browser only and is not synchronized to a server.
